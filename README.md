# Store Product Manager

Tkinter product-management coursework with a MySQL-backed implementation.

**Portfolio:** [Carl Renz Colico](https://github.com/renzkie8) · **Year:** Year 1

## Methodology

Build a desktop inventory interface with product input, database operations and CSV export; retain the earlier UI prototype.

## Results and limitations

Two original source files are preserved. Runtime exports and the bundled phpMyAdmin distribution are excluded. The database server and original table schema must be configured separately.

This upload documents the supplied submission. Experiments, model training, graphical interfaces and external services were not fully rerun during portfolio preparation. See VALIDATION.md for checks actually performed.

## Getting started

Use Python with Tkinter, numpy and pymysql. Configure the local MySQL database/table expected by ProdMngSys.py before starting the GUI. ProdManager.py is an earlier UI prototype. A MySQL schema was not supplied outside the unrelated phpMyAdmin distribution.
